# Phase 14 — CI/CD and production testing gates

Includes a GitHub Actions workflow for linting, tests, and security checks. Verify dependency paths and workflow action versions before using in a real repository. Branch protection must be configured in GitHub settings separately.

To activate this workflow in a GitHub repository, copy `ci.yml` into the repository's `.github/workflows/ci.yml` path. The file inside this learning phase is a template until placed in that location.
